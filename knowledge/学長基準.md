## マガジンから読み取れた学長の投資哲学

- 「優良な高配当株が安く売られてたら、買う」— 見るのは**企業の業績と財政状態**だけ
- **増配が好き**。緩やかで良いので「売上が伸びてる」「EPS（1株あたり利益）が伸びてる」「増配できる」銘柄を好む
- ポートフォリオは**数十銘柄に丁寧に分散**（1銘柄2〜3%程度）。PF全体の利回りは**3.9〜4.35%**程度を目安に設計
- 「TOPIXよりリターンが高く、TOPIXよりリスクが低い」設計を狙う
- 除外理由の典型：**業績不振**、**減配リスクの高まり**（売上・利益が伸びない、配当性向が高すぎる状態が続く）、**他に有望な乗り換え先**
- 流行りモノ（AI・半導体などのモメンタム株）には乗り換えない
- 基本は超長期保有。**売却を検討すべき5つの時**：
  1. 減配・無配転落
  2. 当初の投資シナリオが崩れた
  3. 大きな不祥事を起こした
  4. 有望な乗り換え先が見つかった
  5. 大幅に値上がりした

### ⑦「1株配当の推移」の実装上の注記（アプリ側の都合・学長の発言ではない）

アプリは配当を**権利確定日ベースの暦年**で合計している（会計年度ではない）。そのため
支払時期が年をまたぐと、実際には減配していなくても数%の凹みが出ることがある。
例：マルゼン(5982)の2020年31円→2021年30円。第121回では「20年以上減配なし」と
説明されており、この−3.2%は集計上の見かけの減配。コムチュア(3844)の
2019年31.5円→2020年30.5円も同様（第124回のコラムでは「上場以来19年減配なし・
19期連続増配」と説明されている）。

そこで**5%未満の減少は集計ノイズとみなし、減配として数えない**（`DIV_CUT_TOL = 0.95`）。
ただし前年比だけで見ると、毎年4%ずつのような小さな減配を積み重ねて数年で累積5%超に
なるケースがすり抜けるため、**「過去のピーク比」でも判定する累積ルール**を併用する：

- **前年比**：前年から5%以上落ちた年を減配としてカウント
- **ピーク比**：それまでの最高額から5%以上下振れした**最初の年**をカウント
  （下振れした状態が続く間は重複カウントしない。同じ年が前年比とピーク比の
  両方に該当しても1回だけ数える）

これにより、一時的な凹みで翌年ピークを更新するケースは許容しつつ、じわじわ下がり
続ける実質的な減配は捕捉できる。**この5%という数値は学長の基準ではなくアプリ側の
実装判断**なので、厳格運用に戻す場合は `screener/screen.py` の `DIV_CUT_TOL` を
1.0 にすれば従来どおり「1円でも下がれば減配」になる。

## ポートフォリオの育て方（2024/07/01投稿・買い増し5ルール）

「ポートフォリオを組んだ後、どうすればいいか」への学長の回答。アプリのマイPF機能の判定ロジック。

1. **月に一度、候補銘柄を探す**（現PFのバランスを崩さないか検討して追加）
2. **特定セクターが最大でも20%を超えないように買う** — 超えたセクターは買い増さない。割合の低い業種・保有していないビジネスモデルを入れて分散強化
3. **特定銘柄からの配当金が、PF全体の配当金の3%を超えないように買う** — 1銘柄の減配インパクトを限定する守備ルール
4. **ディフェンシブ銘柄が50%を切らないように買う** — ディフェンシブ＝食料品、医薬品、電気・ガス、陸運、通信など。景気敏感（鉄鋼・化学・機械・輸送用機器など）に偏らせない
5. **当初買値から20%下落したら1回目の買い増し、40%下落で2回目** — ナンピンは2回まで。「下手なナンピン素寒貧」に注意（2025/04/08投稿でも同旨：大きく下げたタイミングで入り、-20%で1回目、買値から-40%前後で2回目）
